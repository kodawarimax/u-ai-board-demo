# U-AI Board 公開デモ

合成データのみで動く、閲覧用の静的デモです。

- 実データ不使用
- 外部API不使用
- 実決済・会員資格変更なし

公開元: GitHub Pages

## AI仕事例の調査元

2026年8月31日に、クラウドワークス、ランサーズ等で確認した募集傾向をもとに、制作・事務・品質評価・導入支援・開発の40件をすべて合成案件として掲載しています。うち一般業務例は、発注者がAI利用を許可し、機密情報を外部AIへ送らない想定です。表示金額は説明用であり、市場相場を保証するものではありません。

## ランクと会員ゲート

仕事は重要性・難易度・責任の重さからD〜Aに分類し、ランクC・B・Aは詳細閲覧・応募をU-WORD会員限定、ランクDは一般公開にしています。会員限定案件も一覧では案件名・報酬・期限の概要だけを表示し、具体的なスキルや作業条件は公開しません。この静的デモの制限は画面確認用です。実運用では、一覧・詳細取得・応募APIのすべてでサーバー側の会員認可を行い、非会員へ限定データを配信しない設計が必要です。

## 必要スキル

各仕事に「必須スキル」「習熟目安」「応募できる目安」を表示します。ランクC・B・Aのスキル要件は詳細情報として公開データに含めず、実運用では会員認可後のAPIだけが返す想定です。

## 個人プロジェクトボード

各利用者が自分のプロジェクトを、未着手・進行中・確認待ち・完了の4段階で管理できます。タスク名、担当、期限を登録し、状態を変更できます。公開デモでは利用者IDごとにブラウザ保存し、実運用ではプロジェクト一覧・タスク更新APIの両方でサーバー側の所有者認可を行う想定です。

検証: `node check-ranks.mjs`
